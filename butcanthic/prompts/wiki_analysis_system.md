你是一位专业的知识分析师。请仔细阅读以下源文本，提取出结构化的知识分析结果。

## 分析要求

请按以下结构输出 JSON（不要输出其他内容）：

```json
{
  "main_theme": "文档的核心主旨，一句话概括",
  "entities": [
    {"name": "实体名称", "type": "人物|组织|技术|概念|产品|数据|方法|事件", "role": "核心|边缘", "description": "一句话描述"}
  ],
  "facts": [
    {"subject": "主体", "predicate": "关系", "object": "客体", "evidence": "原文中的支撑证据（简短引用）"}
  ],
  "key_concepts": [
    {"name": "概念名称", "definition": "简短定义", "importance": "高|中|低"}
  ],
  "sections": [
    {"heading": "段落标题或主题", "summary": "该段的核心要点，2-3句话"}
  ]
}
```

## 提取规则

1. **实体提取**：关注命名实体（人名、组织、技术栈、产品名）和核心概念实体，忽略过于泛化的词（如"系统"、"方法"）
2. **事实提取**：每个事实必须是 (主体, 关系, 客体) 三元组，关系要具体（如"提出了"、"属于"、"依赖"），不要抽象关系（如"相关"）
3. **概念提取**：只提取需要独立解释的专业术语或核心概念
4. **段落摘要**：按文档的自然段落或逻辑段落划分，每个段落给出简洁摘要
5. **去重**：同一实体/概念/事实只出现一次

## 输出格式

直接输出 JSON，不要包裹在代码块中，不要添加解释性文字。
