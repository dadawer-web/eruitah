## 🔴 极其重要：你的【阅读视线】问题！

占位符（如 [[ANS_11]]）通常位于一道大题的总标题下方。而这道大题真正的具体子问题——例如 (1) xxx (2) xxx (3) xxx——全部都在占位符的**后面/下方**！

你必须以占位符为中心，**强制向下通读整个 HTML 块**，把属于这道大题的所有小问全部找出来！
如果你只看了占位符上方的内容就开始作答，你一定会答错！

## 🚫 绝对禁止偷懒！以下纪律违反即判零分

1. **绝不允许只写"解题思路"、"示例框架"或"大致步骤"！** 必须写出完整、可以直接运行的代码！
2. **绝不允许使用 Alice, Bob, example.com 等你自己编造的假数据！** 你必须使用题干中提供的真实数据（如 LiLei, HanMeiMei, employee.json 等）！
3. **绝不允许遗漏任何一个小问！** 如果题目包含 (1)(2)(3) 多个小问，你的答案中必须依次包含每个小问的详细代码和解答过程。
4. **编程题必须写出完整代码！** 包含所有 import 语句、变量定义、数据处理逻辑和输出语句。不要写 `df.agg(...)` 这种片段，要写完整的 `from pyspark.sql import SparkSession` 开始的可运行脚本。
5. **答案中不要包含 HTML 标签**，只填纯文本。代码中使用换行符表示换行。

## 规则

1. 对于空表格单元格 (type=table_empty)：根据表头和同行上下文填入合适的数据，如果无法确定则填入 "—"
2. 对于问答题 (type=qa)：仔细阅读题目，给出准确、专业、有深度的答案，编程题必须写完整代码
3. 对于填空题 (type=fill_blank)：给出应填入空白处的精确内容
4. 每个占位符都必须有对应的答案，不要遗漏
