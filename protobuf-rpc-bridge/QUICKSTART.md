# 快速入门指南

## 5 分钟快速启动

### 前置条件检查

```bash
# 检查 Protobuf
protoc --version
# 预期输出: libprotoc 3.21.12 或更高

# 检查 CMake
cmake --version
# 预期输出: cmake version 3.10 或更高

# 检查 Java
java -version
# 预期输出: openjdk version "17.x.x" 或更高

# 检查 Maven
mvn -version
# 预期输出: Apache Maven 3.x.x
```

### 一键构建和启动

```bash
# 1. 进入项目目录
cd /home/xmy/code/protobuf-rpc-bridge

# 2. 构建（首次需要）
./scripts/build.sh

# 3. 启动系统（两个终端）
# 终端 1: 启动 Java 后端
java -jar java/target/protobuf-rpc-bridge-1.0.0.jar

# 终端 2: 启动 C++ 服务
./cpp/build/bin/chat_server

# 4. 测试（第三个终端）
python scripts/test_client.py
```

## 详细步骤

### 步骤 1: 安装依赖（如果缺失）

#### Ubuntu/Debian
```bash
# C++ 依赖
sudo apt-get update
sudo apt-get install -y \
    build-essential cmake \
    libprotobuf-dev protobuf-compiler \
    libz-dev

# Java 依赖
sudo apt-get install -y openjdk-17-jdk maven

# Python 测试客户端
pip install protobuf
```

#### 安装 muduo（如果系统没有）
```bash
git clone https://github.com/chenshuo/muduo.git
cd muduo
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)
sudo make install
```

### 步骤 2: 生成 Protobuf 代码

```bash
cd /home/xmy/code/protobuf-rpc-bridge
./scripts/generate_proto.sh
```

预期输出：
```

Generating Java protobuf code...
Protobuf code generation completed!
```

### 步骤 3: 构建 C++ 服务

```bash

mkdir -p build && cd build
```

预期输出：

预期输出：

## 常见问题排查

### 问题 1: 端口被占用

**错误信息**：
```
bind failed: Address already in use
```

**解决方案**：
```bash
# 查找占用进程
lsof -i :8888
lsof -i :9999

# 杀死进程
kill -9 <PID>
```

### 问题 2: muduo 未找到

**错误信息**：
```
CMake Error: Could not find muduo
```

**解决方案**：
```bash
# 安装 muduo
git clone https://github.com/chenshuo/muduo.git
cd muduo && mkdir build && cd build
cmake .. && make -j$(nproc) && sudo make install
```

### 问题 3: Protobuf 版本不匹配

**错误信息**：
```
This file was generated by an older version of protoc
```

**解决方案**：
```bash
# 重新生成 Protobuf 代码
./scripts/generate_proto.sh

# 重新构建
./scripts/build.sh
```

### 问题 4: Java 版本不正确

**错误信息**：
```
Unsupported class file major version 61
```

**解决方案**：
```bash
# 安装 Java 17
sudo apt-get install openjdk-17-jdk

# 设置 JAVA_HOME
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
```

### 问题 5: 连接失败

**错误信息**：
```
Connection refused
```

**解决方案**：
```bash
# 1. 确认 Java 后端已启动
lsof -i :9999

# 2. 检查防火墙
sudo ufw status
sudo ufw allow 9999
sudo ufw allow 8888

# 3. 检查网络
ping 127.0.0.1
```
